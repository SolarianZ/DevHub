# DevHub 权威规范与版本化资产

本分类承载 DevHub 的唯一权威协议规范、版本化 Schema 和原始协议示例。涉及公开行为、字段命名、状态转换、错误语义或序列化契约时，应始终先回到这里。

## 权威入口

- 协议规范：[`protocol/Specification.md`](./protocol/Specification.md)
- 版本化 Schema：[`schema/v1.0.1/README.md`](./schema/v1.0.1/README.md)
- 原始协议示例：[`protocol-examples/v1.0.1/README.md`](./protocol-examples/v1.0.1/README.md)

## 使用方式

- 接入方从 [`../user/README.md`](../user/README.md) 进入使用路径，需要核对协议细节时再回到本分类。
- 仓库开发者从 [`../developer/README.md`](../developer/README.md) 进入开发路径，涉及公开契约时以本分类内容为准。
- `docs/assets/` 为静态资源目录，不参与规范资产分层。
